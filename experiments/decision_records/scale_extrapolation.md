# 规模外推实验：数据量 ×10 后方案还能不能打

对应计划补充 T。回答面试官的原话："数据量扩大十倍以后你方案还能不能打。"

## 两组实验

### 1. 政策语料 ×10
合成扩充政策文档（不同租户、地区、生效期的变体），重测：
Recall@K / MRR / 引用有效率 / P95 / 索引大小 / 构建时间。

重点观察：HNSW 参数是否需要重调；**metadata 过滤后 ANN 的可达性是否退化**
（过滤 + ANN 是经典陷阱：先取候选再过滤会导致结果不足）。

### 2. 订单 / 案件数据 ×10
沿用 V1 `database_benchmark` 已有的噪声数据手法，重测关键查询 P95，
验证 V1 的联合索引优化结论在更大数据量下是否仍成立。
